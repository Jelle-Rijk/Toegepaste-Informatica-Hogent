<h1>Centrale limietstelling en confidence intervals</h1>

# Central Limit Theorem

CLT = Als de grootte van een random sample (n) groot genoeg is, benadert de probabiliteitsverdeling de normale distributie (onafhankelijk van de distributie van de populatie)

De normale distributie zal dan een gemiddelde van $\mu$ krijgen en een standaardafwijking van $\frac{\sigma}{\sqrt{n}}$

n=30 is meestal genoeg om een normale distributie te zien.

# Point estimate

Best guess voor een bepaalde parameter op basis van de sample (vb. de mean)

# Confidence interval

= formule die een point estimate maakt met een bepaalde zekerheid dat deze gaat kloppen.

De formule is meestal: Point Estimate $\plusmn$ Factor x Standard Error.

Point estimate = de mean van de sample <br>
Standard error = $\frac{\sigma}{\sqrt{n}}$
Factor = ongeveer 2

In DSAI -> enkel confidence interval berekenen voor de mean

## Confidence interval voor het gemiddelde van een grote sample

De sample heeft een gemiddelde van $bar{x}$, we zoeken een interval met gemiddelde $bar{x}$ waarvan we 95% zeker zijn dat het gemiddelde van de gehele populatie erin ligt. Het interval krijgt de vorm [$bar{x}$ - b, $bar{x}$ + b]

Het level of confidence krijgt de notatie (1-&alpha;) dat betekent dat de delen buiten het interval samen &alpha; zijn en één staart buiten het interval dus gelijk is aan $\frac{\alpha}{2}$

**Formule:** <span title="De probabiliteit dat x in [x-b, x+b] ligt.">$P(\bar{x}-b\lt\mu\lt\bar{x}-b)$</span> <span  title="Level of confidence = 95%">$=1-\alpha=0.95$</span>

Het confidence interval berekenen:

1. Gebruik de CLT om de normaalverdeling uit te rekenen => $Nor(\mu,\frac{\sigma}{\sqrt{n}})$
2. Bereken de z-score door $\frac{\bar{x}-u}{\sigma}$ te delen door de standaard error $\frac{\sigma}{\sqrt{n}}$
3. Bereken de z-score van $1-\frac{\alpha}{2}$ met `stats.norm.isf(1 - (1 - alpha / 2), loc=0, scale=1` (standaardnormaaldistributie) (= in volgende stappen vervangen door 1.96 => 95% confidence)
4. &mu; moet in het interval [$\bar{x}-1.96*standaarderror$,$\bar{x}+1.96*standaarderror$] liggen.

In Python kan je het interval ook berekenen met `stats.norm.interval(1-alpha, loc=mu, scale=sigma/np.sqrt(n))`

## Confidence interval voor het gemiddelde van een kleine sample

### Bij normale verdeling

Zelfde methode als bij het gemiddelde van een grote sample.

### Andere verdelingen

Als <span title="De grootte van een sample moet minimaal 30 zijn om de CLT te kunnen gebruiken.">$n<30$</span> kunnen we de normale distributie niet gebruiken. Hiervoor gebruik je de Student-t functie.

Deze functie krijgt een parameter <abbr title="degrees of freedom">df</abbr> / <abbr title="degrees of freedom">df</abbr>. df$=n-1$<br>
Hoe hoger df, hoe meer de t-functie op een normale distributie lijkt.

In python:

| Functie                  | Omschrijving                                |
| ------------------------ | ------------------------------------------- |
| `stats.t.pdf(x, df=d)`   | probability density voor x                  |
| `stats.t.cdf(x, df=d)`   | P(X < x)                                    |
| `stats.t.sf(x, df=d)`    | P(X > x)                                    |
| `stats.t.isf(1-p, df=d)` | resultaat is hoger dan p% van de resultaten |

### Confidence interval via t-functie berekenen (kleine samples en ongekende standaardafwijking)

Confidence level 95% => $\frac{a}{2} = 0.025$ => 1-0.025 = 0.975 <br>
Sample size 5 => df = n-1 = 4

1. Gebruik `stats.t.isf(1-0975, df=4)` (uitkomst = 2.776)
2. Confidence interval is: $[\bar{x}-2.776*\frac{s}{\sqrt{n}},\bar{x}+2.776*\frac{s}{\sqrt{n}}]$

s is hier de standaardafwijking van de populatie en het deel na de \* is dus hetzelfde als $\frac{\sigma}{\sqrt{n}}$

In Python kan je `stats.t.interval(1-alpha), df=n-1, loc=mean, scale=sample_standard_deviation/np.sqrt(n)` gebruiken.
