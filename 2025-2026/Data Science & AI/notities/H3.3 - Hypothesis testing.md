<h1>Statistical Hypothesis Testing</h1>

# Definities

- Null hypothesis = Basishypothese, je gaat ervan uit dat de hypothese waar is.
- Alternative hypothesis = Conclusie wanneer de nulhypothese waarschijnlijk niet klopt.
- Critical region / Rejection region = Waarden die kunnen aantonen dat de null hypothesis niet klopt.
- Acceptance region = Waarden die kunnen aantonen dat de null hypothesis wel klopt.
- Critical value (g) = Grenswaarde van de critical region
- Significance Level = Kans dat de null hypothese niet klopt.

Hypothesis testing => Kans berekenen dat een bepaalde test statistic kan geobserveerd worden wanneer de nulhypothese waar is.

Een acceptance region neemt meestal 5% van de mogelijke waarden in.

H0 = nulhypothese <br>
H1 = alternatieve hypothese

=> Bij acceptatie van H0, zeg je dat er geen bewijs TEGEN H0 is. <br>
=> Bij afwijzing van H0, zeg dat er bewijs is dat H0 niet klopt.
