<h1>Beslissen wie het project uitvoert - Commerciële fase</h1>

# Make or buy

Als het project kan doorgaan -> beslissen om het zelf te maken of aan te kopen.

Dit is afhankelijk van:

- Kennis van de werknemers
- Beschikbaarheid van mensen met de juiste kennis

Op basis van de beslissing kom je in andere fasen terecht:

- Externe uitvoering -> commerciële fase
- Interne uitvoering -> uitvoeringsfase

# Commerciële fase

Lastenboek in deze fase = RFP (Request for Proposal) / RFI (Request for Information)

| RFP                              | RFI                               |
| -------------------------------- | --------------------------------- |
| Request for Proposal             | Request for Information           |
| Vraagt een algemene kostenraming | Vraagt een offerte                |
| Niet bindend                     | Bindend (binnen bepaalde termijn) |

# Deliverable - Project proposal

Het projectvoorstel bevat alle mogelijke functionaliteiten die gevraagd worden in de nieuwe applicatie + relevante informatie voor het project. Daarnaast bevat het een kostenraming en voorlopige tijdelijn.

Het projectvoorstel bevat:

- De context van het project (interne cultuur, situatie binnen de organisatie)
- Doelen van het project (SMART)
- Algemene beschrijving van de beoogde oplossing + assumpties om een prijs te bepalen
- Kosten: Ofwel een fixed price (risico ligt bij de leverancier) ofwel op basis van time en material (risico is verdeeld over beide partijen)
- Voorwaarden: Dingen die noodzakelijk zijn om het project uit te voeren (vb. bepaalde versie van software)
- Assumpties: Er is nog geen analyse uitgevoerd, dus sommige zaken moeten verondersteld worden om een raming van de prijs te kunnen maken.
- Voorlopige tijdlijn van het project

# Rollen en verantwoordelijkheden

- Business analist: Stelt lastenboek op.
- Eindgebruiker: levert inhoud voor het lastenboek en helpt kiezen
- Ontwikkelaars: helpen bij de proposal voor een technische oplossing
- Projectmanager: bewaakt overzicht en haalbaarheid project

# Aandachtspunten

- Maak duidelijke en eenduidige afspraken (vooral ook bij scope)
- Onderhandel correct: Beide partijen moeten achteraf ook nog samenwerken.
