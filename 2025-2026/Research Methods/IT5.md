# Plan van aanpak

Een plan van aanpak splitst het onderzoek in fasen op.

Vermeld:

- Gebruikte technieken
- Doelstellingen van elke fase
- Volgorde / dependencies
- Timing
- Resultaat (artefact) dat je verwacht op te leveren na elke fase.

Vaak voorkomende problemen:

- Verkeerde volgorde
- Vaag
- Ongeschikte technieken
- Onmeetbare criteria (vb. gebruiksvriendelijkheid)

Typische opbouw van fasen:

- Casus / probleem voorstellen
- Requirements verzamelen -> doel = criteria oplijsten waaraan oplossing moet voeldoen (vb. via MoSCoW-methode)
- Long list -> alternatieven die in aanmerking kunnen komen als oplossing + aftoetsen aan requirements
- Short list -> selectie van interessantste alternatieven
- Proof of concept -> valideren of beste alternatief het probleem kan oplossen.
- Conclusies -> aanbevelig over beste alternatief + hiaten identificeren
